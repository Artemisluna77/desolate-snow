# 05 — 目录页

**What to build:** 用户在目录页可通过筛选栏组合条件浏览番剧:地区、版本、首字母、年份、季度、状态、类型、排序;筛选状态编码进 URL 查询参数,刷新或分享链接后结果一致;底部分页可翻页,页码同样进 URL。列表条目含封面、集数徽标、标题、元信息行与简介。

**Blocked by:** 03

**Status:** resolved

- [x] 8 维筛选栏 + 排序,多选组合查询真实数据
- [x] 筛选与页码同步到 URL,前进/后退/刷新状态保持
- [x] 结果总数与分页展示,翻页不丢失筛选条件
- [x] 数据源无对应能力的筛选(如资源版本)保留 UI 并标注说明
- [x] 列表条目布局对照原站字段

## Comments

- 2026-08-30:实测发现 POST search 的 filter(years/tags)在无关键词时完全失效(固定返回 1000 条冷门池),目录浏览改用 GET /v0/subjects?type=2&year=YYYY(年份过滤真实生效,返回 total,默认序即人气序)。排序组移除、以「按人气排序」标注;类型/地区/版本/状态保留 UI,选中时黄色提示条说明数据源无该过滤能力。浏览器验证 ?year=2024 返回 1192 条且结果全为 2024 首播。
